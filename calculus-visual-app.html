📐 두 점의 기울기

두 점 P와 Q를 이은 선의 기울기를 구해요.
슬라이더로 점 P를 움직이거나 간격 h를 바꿔 보세요!

📖 단계별 이야기

1️⃣ 두 점을 잇는 선 → 평균 기울기
2️⃣ 점을 점점 가깝게 → 기울기가 변해요
3️⃣ 완전히 붙으면 → 그 점의 정확한 기울기!

🔢 미분 공식

y = xn 이면 y' = n·xn-1

예) y = x² → y' = 2x
점 P(1,1)에서 기울기 = 2×1 = 2

📖 왜 조각을 많이 나눌까요?

🍫 초콜릿 한 판의 넓이를 재고 싶어요.
칸을 많이 나눌수록 더 정확해져요!

슬라이더를 오른쪽으로 밀어보세요 → 점점 정확한 넓이가 나와요!

📏 정확한 넓이와 비교

y = x² 아래 넓이(0~2)의 정답은 약 2.667이에요.
조각이 많아질수록 이 숫자에 가까워져요! ∫₀² x² dx = [x³/3]₀² = 8/3 ≈ 2.667
직사각형이 많아질수록 수렴!

🔢 적분 공식

∫ xn dx = xn+1/(n+1) + C

예) ∫ x² dx = x³/3 + C
예) ∫ 2x dx = x² + C
