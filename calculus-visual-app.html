📐 평균변화율

두 점 P(x, x²)와 Q(x+h, (x+h)²) 사이의
기울기 = Δy / Δx = (2x·h + h²) / h

슬라이더로 점 P를 움직이거나 간격 h를 바꿔 보세요!

🔢 미분 공식 미리보기

y = xn 이면
y' = n · xn-1

예) y = x² → y' = 2x
점 P(1, 1)에서 기울기 = 2×1 = 2

적분의 의미

🧩 적분은 잘게 쪼갠 조각들을 다시 더해서 전체 넓이(또는 거리)를 구하는 거예요.
직사각형을 더 얇게 쪼갤수록, 더 정확한 답에 가까워져요.

📏 실제 넓이와 비교

y = x²를 0부터 2까지 적분하면:
∫₀² x² dx = [x³/3]₀² = 8/3 ≈ 2.667

직사각형이 많아질수록 이 값에 가까워지는 것을 확인해 보세요!

🔢 적분 공식 미리보기

∫ xn dx = xn+1 / (n+1) + C

예) ∫ x² dx = x³/3 + C
예) ∫ 2x dx = x² + C
